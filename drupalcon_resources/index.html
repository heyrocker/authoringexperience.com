Building A Better Authoring Experience - Resources

March 24, 2025 by Greg Dunlap

Thank you for attending my talk, Building a Better Authoring Experience, at DrupalCon Atlanta. This page contains links to many of the resources I reference in the talk. Hope you find them useful! If you want to read more about this topic then you might want to check out my book Designing Content Authoring Experiences. It is available in paperback and EPUB on all major platforms.

Resources

  • Real World Content Modeling, by Deane Barker

  • Designing UX: Forms, by Jessica Enders

  • Form Design Patterns by Adam Silver. Adam also has an excellent newsletter that often talks about form design, which you can sign up for at his website.

  • Inline Entity Form module

  • Type Tray module

  • Require On Publish module

  • Disable HTML 5 Validation module

  • WCAG Authoring Tool Accessibility Guidelines (ATAG)

  • Drupal core ATAG issues

  • Editoria11y module
